# 個人／業務空間交付

## 已實作

- iPhone：個人「生活／明細／設定」；業務「工作台／收據／匯出／設定」。
- Mac：每個視窗獨立空間與導航；個人生活總覽、明細及分析；業務工作台、收據、已確認、分析及稅務匯出。設定共用；實驗性會計入口保留原有開關，僅業務側顯示。
- 個人暖色、大留白、最近記錄時間線；業務冷藍、緊湊待辦清單。支援淺色、深色及大字；切換入口包含文字與圖示。
- 根導航明確傳遞 ReceiptLedger；查詢、分析、新增用途與批量操作均限制在當前空間。資料庫、附件、Keychain 及原有用途不遷移。
- 本月總額只計已確認且有交易日期的記錄，按幣種分開；未確認／無日期項目另有入口。
- 收據工具保留 Gemini 範圍選擇、限流重試與批量確認；個人明細預設摺起工具。
- 每個視窗保存兩邊導航、收據搜尋／篩選及分析篩選。編輯、匯入及批次處理期間鎖定切換，避免改變進行中的用途或範圍。

## 驗證範圍

- 新增混合用途、收入／支出、多幣種、跨月份、無日期及未確認項目的總額測試。
- 新增視窗 session 隔離、篩選保存／恢復及多個操作鎖定測試；原有匯入測試驗證業務用途傳遞。
- iOS 渲染測試涵蓋兩個首頁、淺色及深色大字模式；Mac 渲染測試涵蓋兩個空間及兩種外觀。
- 渲染測試不等於 VoiceOver 實際朗讀、實機批量操作或真實 Gemini API 驗證。
- 建置、測試及畫面證據存放於 `/Volumes/External SSD 4TB/DeveloperData/Temp/PocketPal-Spaces`。

## 實機驗收步驟

1. 在 Ricky 頂部切換個人／業務，檢查首頁及底部導航有明顯差異。
2. 個人「記一筆」、業務「加入收據」各自帶入正確用途；取消表單後能恢復切換。
3. 業務點擊三類待辦，檢查清單範圍；Gemini／批量確認只處理業務及報銷。
4. 在兩邊分別搜尋／篩選，再切換返回；重開 App 驗證空間與導航恢復。
5. Mac 開兩個視窗，分別停留個人及業務，確認互不影響。
6. VoiceOver 逐一朗讀切換、待辦及新增操作；真實 API 批次由用戶主動開始，不為驗證自動上傳現有收據。
