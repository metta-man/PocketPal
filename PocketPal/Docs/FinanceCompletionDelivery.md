# PocketPal 收支工作流交付

日期：2026-09-09。按用戶「繼續完成前述所有功能」授權執行，保留所有既有未提交修改。

## 入口

- iOS：收支分頁。macOS：側欄「收支管理」。
- 舊收據詳情亦可進入「付款、附件、項目及審批」。
- 設定的「整理及匯出收支紀錄包」整合新資料；完整備份／還原在收支管理內。

## 功能與行為

| 功能 | 已實作行為 |
| --- | --- |
| 收入及各類營運支出 | 快速新增，支援個人／業務、原幣、分類、日期及備註 |
| 人工 | 應發、員工扣款、額外僱主成本；可修訂、分次付款、附證明；不自動計算法定供款或薪酬 |
| 定期項目 | 每週／月／季／年；到期產生未確認未付款紀錄；支援月底及重複執行去重；可暫停／恢復；可選開啟頁面時自動產生 |
| 欠收欠付 | 到期日、目前餘額、逾期篩選、部分付款、錯誤付款撤回及歷史紀錄 |
| 退款及非營業資金 | 支出退款抵減支出；銷售退款抵減收入；轉帳、注資／提取、借貸本金、歸還墊支不計入營業收支 |
| 墊支 | 記錄代墊人；原始費用計一次，歸還墊支使用獨立非營業資金類別 |
| 多附件 | 每筆可加多份图片／PDF，獨立預覽、穩定 ID、完整匯出及還原 |
| 缺件及重複 | 日期／金額／證明／未付款提示；疑似重複清單；不自動刪除；可標記所需文件已備齊 |
| 搜尋及分類 | 搜尋金額、客戶、項目、員工、備註；日期篩選及狀態篩選；项目摘要匯出 |
| 銀行匯入 | HKD CSV 預覽、逐行選取、相同匯入去重、保留同批相同交易的筆數、匹配已有紀錄、待對帳清單 |
| 舊會計資料 | 預覽匯入發票、帳單、人工及定期項目，保留原實驗資料，不直接改動獨立 store |
| 備份／還原 | 連原檔、OCR、付款、定期設定、審批、修改紀錄，SHA-256 附件校驗；新增式還原，不覆蓋同 ID；可按新增日期分批 |
| 員工交接 | 提交／批准／退回補件；匯出提交檔、匯入待審批；姓名是本機紀錄，不宣稱登入驗證或即時多人同步 |
| 文件準備 | 自訂所需文件、工時及期間／項目篩選、官方資訊連結；不自動判斷資助資格 |
| 完整紀錄包 | 收支、月度現金收支、付款、人工、項目摘要、附件索引、缺件及修改紀錄 CSV，連圖片及 PDF |

## 金額及資料完整性

- 沿用既有 Receipt 和主附件，新增一個可選 metadata JSON 欄位；不重建、清空或合併現有資料庫。
- 付款及摘要使用 Decimal；保留原幣，不把參考匯率當銀行實際成交價。
- 新增的付款追蹤紀錄只有實際付款才計現金收支。未啟用付款追蹤的舊紀錄沿用原日期／全額，畫面及匯出說明此規則。
- 期間匯出包含該期間交易及該期間有付款的紀錄；月度摘要按付款日期；付款明細保留所選紀錄全部付款供追溯。
- 已記付款後，不可直接改貨幣或方向，總金額不可低於已付金額。人工金額透過人工表格修訂。
- 收據修改、付款及分類操作均留歷史；已批准紀錄更改後會回到待審批。失敗時回復本次擁有的修改；備份匯入失敗清除本次新建的紀錄及檔案。
- 備份不含 API keys。缺原檔時停止建立完整備份；普通紀錄包則明確列出缺件。
- 單一備份上限 250 MB，可按新增日期分批。還原採新增式，不能覆蓋現有 ID；舊獨立實驗 store 不屬此備份，需要先匯入所需業務紀錄。
- 工作表公式文字會中和，合法負數仍維持可計算的數值。
