# 收支紀錄包：第一段交付

日期：2026-09-09。此為第一段交付紀錄；後續功能及目前驗證範圍見 [FinanceCompletionDelivery.md](FinanceCompletionDelivery.md)。

## 已落實範圍

設定 → 整理及匯出收支紀錄包 → 選個人／業務空間及期間 → 預覽合計、排除筆數及缺件 → 匯出資料夾。

- 日期按香港曆日（開始及結束日均包含）篩選。無日期紀錄明確列出數量，使用者選擇是否包含。
- 可選所有符合期間紀錄，或只選已確認紀錄；此選項並非稅務資格判定。
- `receipts.csv` 包含收支類型、原幣金額及穩定 UUID 附件路徑。
- `monthly-summary.csv` 按月、原幣整理收入、支出、淨收支；Decimal 加總避免二進制浮點加總誤差。
- `Attachments` 保留原始 JPEG 和 PDF 位元組。
- `missing-items.csv` 列出欠日期、有效金額、未確認、未附證明、無法讀取原檔等問題。無附件不直接判定為不合資格。
- `README.txt` 列明期間、範圍、排除筆數、待處理筆數及原幣總數。
- 缺有效金額保留空白，不計入摘要；此功能不寫入或變更原紀錄。
- CSV 對可能執行的公式文字加以中和。

## 後續範圍

依序處理定期收支、未收／未付／部分付款，再設計退款／墊支／轉帳、多附件、備份還原及協作。現有會計模組需先驗證可用範圍，不能僅因有資料模型就視為完成。

此輪紀錄包只涵蓋 Receipt 帳簿；不宣稱包含隔離會計資料庫的人工、發票或銀行交易。介面應清楚說明此範圍。現有 Receipt 每筆一個附件；多附件模型尚未實作。

## 驗證

- 新測試覆蓋香港日期邊界、跨工作區排除、無日期選擇、確認狀態、圖片／PDF 原檔及索引、缺件、CSV 公式處理與合計。
- macOS 相關測試及 iOS 模擬器編譯結果見本次交付訊息及 `.build/delivery-*.log`。
